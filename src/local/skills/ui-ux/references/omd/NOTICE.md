# oh-my-design reference set — notice

These files are generated by [`sync.py`](./sync.py) from
[`kwakseongjae/oh-my-design`](https://github.com/kwakseongjae/oh-my-design) at the commit in
[`UPSTREAM`](./UPSTREAM). The upstream repository is MIT-licensed; its licence is kept verbatim in
[`LICENSE`](./LICENSE). [`MANIFEST.json`](./MANIFEST.json) holds the sha256 of every vendored file.

What is here: for each archive reference, the `DESIGN.md` YAML frontmatter (design tokens) copied
verbatim, plus a three-line stub that names the company and links the full upstream file. Registry
names are `omd-<id>` (upstream ids with dots, such as `linear.app`, become `linear-app`).

What is not here: the DESIGN.md prose, `reference.json`, research notes, logos, screenshots and font
files. Read the prose at `https://oh-my-design.kr/<id>/design.md` when a design decision needs it; do
not mix a newer prose file with these pinned tokens.

Rights. Each DESIGN.md describes a company's design, which belongs to that company; oh-my-design
reproduces it for educational reference (upstream README). Neither MIT nor "educational reference"
grants rights in a third party's brand. Pages rendered with these tokens are labelled
"레퍼런스 토큰 적용본" (reference-token rendition), credit the company and oh-my-design, list every
derived value, and never load a proprietary brand font or logo.

Integration decision: trinity consensus (grok-elon · astra-zhuge · fable-zhuge, round 2/5,
2026-10-26) — tokens-only vendoring, separate generated index merged by the html resolver.
