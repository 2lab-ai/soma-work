### SSOT_1 — 2026-11-16 Slack (원문 그대로)

> soma-work  대시보드 다음처럼 개선해줘.
>
> 1. 작업 세션에서 다음을 볼수 있도록해줘.
> - pr별 소스 변경점을 볼수 있고 실제로 변경점 파일별로 github pr에서 보듯 볼수 있다.
> - 각각의 해당 세션에서 실제로 만든 각각의 pr과 전체 변경점을 볼수 있다.
> - 여러 repo에 변경점이 있는 경우, 루트에서 각각의 repo별로 트리 구조로 확인할 수 있음.
> - 디폴트로 이걸 보여주는 위치는 디테일 작업 카드의 "대화", 작업 로그 탭에 changes 탭을 추가하고 거기서 볼수 있다.
> - 디테일 작업 카드에서는 어떤 파일들이 변경되었는지 트리 구조로 볼수 있다. 여기서 특정 파일을 누르면, 전체 화면에서 디렉토리 트리 패널이 있는 파일 뷰어가 표시되어 변경점을 자세히 볼수 있다.
>
> 2. 파일의 변경점에 대한 데이터가 세션에 저장되고 커밋하지 않은 변경점과 커밋한  변경점과 그리고 PR로 올리고 실제로 머지된 변경점을 각각 별도로 확인할 수 있다.
> - 통계 데이터에 제대로 작동안하는 코드 변경 데이터가 있는데 여기에 이 코드 변경점 통계가 수집된다.
> - 모델이 이 데이터를 세션 데이터에서 확인할 수 있고, 작업만 하고 커밋하지 않은 변경점에 대해 인지할 수 있게 한다.
>
> 이 내용을 자세히 리서치하고 작업 계획을 $local:using-dotprd 로 만든후 구현한다.

## SSOT-TASK-TREE

- **T1** — PR별 소스 변경점을 파일별로 GitHub PR처럼 본다 (SSOT_1 1-①)
- **T2** — 세션이 실제로 만든 PR 각각과 전체 변경점을 본다 (SSOT_1 1-②)
- **T3** — 여러 레포의 변경은 루트 아래 레포별 트리로 본다 (SSOT_1 1-③)
- **T4** — 기본 위치 = 상세 카드의 대화 · 작업 로그 옆 changes 탭 (SSOT_1 1-④)
- **T5** — 상세 카드에서 바뀐 파일을 트리로 보고, 파일을 누르면 디렉터리 트리 패널이 있는 전체 화면 뷰어에서 변경을 자세히 본다 (SSOT_1 1-⑤)
- **T6** — 변경 데이터가 세션에 저장되고 커밋 안 함 · 커밋함 · PR · 머지됨을 따로 본다 (SSOT_1 2)
- **T7** — 통계의 코드 변경 데이터가 이 데이터로 모인다 (SSOT_1 2-①)
- **T8** — 모델이 세션 데이터에서 이 데이터를 보고, 커밋하지 않은 변경을 안다 (SSOT_1 2-②)
- **T9** — 리서치 → `.prd` 계획 → 구현 (SSOT_1 끝 문장)
