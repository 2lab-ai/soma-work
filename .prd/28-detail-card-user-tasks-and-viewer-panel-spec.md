# 28 — 상세 카드: 사용자 할 일은 목표 탭 안, 변경점 뷰어는 두 모드

요약: 상세 카드의 사용자 할 일이 탭 줄 위에서 카드 절반을 차지해 대화를 밀어낸다. 이제 목표 탭 안으로 들어가 누르면 보이고 다시 누르면 접힌다. 대기 수는 탭 라벨에 남는다. 변경점 뷰어는 두 모드다. 데스크톱에서 상세 카드 왼쪽이 넓으면 그 자리(보드)에 파일만 띄우는 패널, 아니면 지금의 전체 화면.

## 1. 문제 (AS-IS, [LIVE] dev v0.3.56 `cda9d40a`, 하네스 = 배포 빌드 + dev 저장본 사본, 사용자 할 일 대기 1 · 완료 1)

| 화면 | 사용자 할 일 영역 | 탭 줄(목표 …) | 첫 섹션 탭(대화) | 뷰어 |
|---|---|---|---|---|
| 1440×900 | 1001,−27 439×460 | y 433 | y 471 | modal 0,0 1440×900 — 상세 카드(1000,56 440×844)까지 덮음 |
| 1024×768 | 585,−78 439×460 | y 382 | y 420 | modal 0,0 1024×768 |

- 사용자 할 일 영역은 탭 줄 위라 접을 수 없다. 1440×900에서 상세 카드 높이 844px의 54%(460px)를 차지하고, 대화는 y 471 아래 남은 곳에만 보인다.
- 뷰어는 늘 modal이라 열려 있는 동안 상세 카드를 쓸 수 없다. 다른 파일은 뷰어 안의 트리로만 고른다. 1440 폭에서는 보드 자리(1000px)가 비어 있는데도 그렇다.

## 2. 목표 · 비목표

목표
- G1 사용자 할 일 전체(대기 · 끝난 것)는 목표 탭 안에 있다. 탭을 누르면 보이고 다시 누르면 접힌다.
- G2 접혀 있어도 대기 중인 필수 할 일의 수는 보인다. 목표 탭 라벨에 대기 배지가 붙는다(카드 면 배지와 같은 수).
- G3 상세 카드가 옆에 붙은 데스크톱에서 카드 왼쪽이 넓으면, 뷰어는 그 자리에 파일만 띄운다(패널 모드). 트리는 상세 카드의 변경점 탭이 맡는다.
- G4 두 모드를 오간다. 패널의 "전체 화면" 버튼과 전체 화면의 "패널로" 버튼(패널이 들어갈 때만)을 쓰고, 고른 것은 기기에 기억한다.

비목표
- 사용자 할 일의 내용 · 응답(완료했어요 / 안 됐어요) · Slack 카드는 바꾸지 않는다.
- diff 렌더(hunk · 줄 번호 · 층 블록)는 26 §4.2 그대로다.
- 폰 · 접힌 폴더블(< 840px)은 지금 그대로 시트 + 전체 화면이다.

## 3. 사용자 할 일 → 목표 탭 (WU-A)

- 레이아웃에 목표 탭이 있으면 사용자 할 일 영역은 목표 탭의 내용(목표 · 일시정지된 목표) 아래에 놓인다. 목표 탭이 열려 있을 때만 보인다. 카드를 열면 탭은 닫혀 있다(탭 줄 규칙 그대로).
- 목표 탭 라벨: `목표 2/5` 다음에 대기 배지 `할 일 1`(대기 톤)이 붙는다. 수 = 대기 중인 필수 할 일(선택 할 일은 세지 않는다 — 카드 면과 같다). 탭 title에 `사용자 할 일 대기 n`을 더한다.
- 목표가 없어도 사용자 할 일이 있으면 목표 탭은 눌린다(빈 탭 비활성 규칙의 예외).
- 레이아웃에 목표 탭이 없으면(설정에서 끈 경우) 지금처럼 탭 줄 근처에 늘 보인다. 숨길 탭이 없는데 숨기면 할 일이 사라진다.

## 4. 변경점 뷰어 — 패널 · 전체 화면 (WU-B)

모드 판정 — 파일을 열 때, 창 크기나 상세 카드 폭이 바뀔 때:
- 패널: 상세 카드가 옆에 붙은 화면(창 폭 ≥ 840px, 카드가 열려 있음)이고 카드 왼쪽 폭(창 폭 − 카드 폭) ≥ 640px이며, 기기에 기억된 선택이 "전체 화면"이 아닐 때.
- 그 밖: 전체 화면(26 §4.2).

패널 모드
- 자리: 위는 상단 바 아래(상세 카드와 같은 선), 아래는 화면 끝, 왼쪽 끝부터 상세 카드 왼쪽 가장자리까지 — 보드가 있던 곳. modal이 아니라 상세 카드를 그대로 쓴다.
- 머리: 범위 · 레포 › 경로 · 이전/다음 파일 · 전체 화면 · 닫기. 뷰어 안 트리 패널과 "파일 목록" 버튼은 없다.
- 파일 고르기: 상세 카드 변경점 탭의 파일 줄을 누르면 패널이 그 파일로 바뀐다. 탭의 트리는 지금 파일을 강조한다.
- Esc: 패널만 닫는다(상세 카드는 남는다). 포커스가 패널에 있든 상세 카드에 있든 같다. 닫으면 포커스는 그 파일의 줄로 간다.
- 상세 카드가 닫히거나 다른 세션 카드로 바뀌면 뷰어도 닫힌다.
- 창이나 상세 카드가 넓어져 패널이 들어가지 않으면 같은 파일로 전체 화면이 된다. 다시 넓어지면 패널로 돌아간다(기억된 선택이 "전체 화면"이 아니면).
- 새 작업 버튼(FAB)은 패널이 열린 동안 숨는다(패널 오른쪽 아래를 가리므로).

전체 화면 모드
- 26 §4.2 그대로다. 머리에 "패널로" 버튼이 더해진다(패널이 들어갈 때만 보임). 누르면 기억된 "전체 화면"이 지워지고 패널로 간다.

## 5. 구현 경계

- WU-A — `src/conversation/dashboard.ts`
  - `#panel-user-actions`를 `#panel-goal-paused` 아래로 옮긴다.
  - `detailSpecOf`(view-layout-client)는 tabs에 `goal`이 있으면 show에 `goaltab`을 더한다.
  - CSS `body[data-detail~="goaltab"] .slide-panel:not([data-midtab="goal"]) #panel-user-actions { display: none }`.
  - `panelMidTabsOf`: goal 탭에 `wait`(= `userActionsWaiting`)를 둔다. 할 일이 있으면 `empty` = false.
  - `renderPanelMidbar`: 대기 배지 `pm-wait`. en-page 카탈로그에 새 문구를 넣는다.
- WU-B — `src/conversation/code-changes-client.ts`
  - 순수 함수 `chgViewerModeFor(vw, panelW, docked, pref)` → `panel` | `full`. 기억은 `localStorage['soma-chg-viewer']`(`full` | 없음).
  - dialog `data-mode`: 패널 = `show()`, 전체 화면 = `showModal()`. 모드를 바꿀 때는 닫았다 다시 연다(`_chg.switching`이 close 정리를 막는다).
  - `chgCloseViewer()`. 패널에서는 `chgPaint`가 지금 파일 줄을 강조한다.
  - 창 `resize`와 상세 카드 `ui-resize`에서 `chgSyncViewerMode()`를 부른다.
  - `src/conversation/dashboard.ts`: `closePanel`과 세션 전환에서 뷰어를 닫는다. 상세 카드의 `ui-close`와 페이지 Esc는 패널이 열려 있으면 패널만 닫는다.
