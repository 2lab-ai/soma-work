## 0. 한 줄 정의

에이전틱 태스크(세션) 하나는 세 서피스에 나온다. **접힌 카드**는 분류("나를 기다리나, 움직이나"), **펼친 카드**는 여기서 처리
(카드 상태에 따라 내용이 바뀐다 — 질문·승인 / 지금 하는 일 / 결과), **디테일 패널**은 파악과 조종(기록 전부, 모든 숫자, 들어가 볼 수
있는 에이전트 트리, goal과 모델·effort, 대화)이다. 필드마다 집은 한 서피스다. 집에서 전부 보이고, 다른 서피스는 숫자·배지·한 항목만
보이며 집으로 이어진다. 펼친 영역은 그 위에 그대로 보이는 접힌 카드의 내용을 다시 그리지 않는다.

- 목록 항목은 상태·주의가 필요한 이유·진행 지표 하나·최근성만 싣는다. 토큰·비용·모델 설정·로그를 목록에 싣는 제품은 없다(Codex 목록

- 펼친(peek) 단계는 그 항목 하나를 자리에서 처리하게 한다. 예외적인 부분을 먼저 연다(Actions는 실패 스텝을 자동으로 펼친다, Devin
  hover는 최신 응답 몇 줄). 자식 구조는 접힌 한 줄로 보여 준다(Copilot 서브에이전트 HUD).
- 상세는 기록과 조종이다: 로그·대화·입력창(Copilot·Claude Code), 사용량·환경(Claude Code 세션 레일), 모델·effort는 입력창 줄
  (Claude Code). 패널 머리는 앱 액션 하나 + 패널 액션 둘 + 닫기(Atlassian).
- "작은 위젯의 내용을 큰 영역에 그냥 늘리지 말라"(Apple HIG), "공개 단계가 둘을 넘으면 사용성이 낮다"(NN/g) — 세 단계가 같은 내용을
  담으면 실패다. 가운데 단계는 다른 일을 할 때만 존재 이유가 있다.

### 3.2 펼친 카드 — 상태로 정해지는 섹션 (`renderCardBody`)

- 블로커가 언제나 먼저: 권한 요청(닫힌 칸 제외) → 자동 재개 줄 → 질문(질문 대기일 때). 데이터로 정한다(칸이 아니라).
- 실행 중(`working`): task 창 → 에이전트 → 최근 지시 ↔ 응답.
- 질문 대기(`waiting`): 최근 지시 ↔ 응답 → 산출물 → task 창 → 에이전트.
- 유휴·닫힘(`idle`·`closed`): 최근 지시 ↔ 응답 → 산출물 → 에이전트.
- 공통 끝: goal 한 줄 → 짧은 참조(+ 환경 배지) → 컨트롤 줄(모델·effort 전환 · 상태 액션 · Slack · 작업 로그) → 대기 전환 안내.
- 640px 미만에서는 컨트롤 줄의 모델·effort가 토글 하나(`opus-5-5[1m] · high ▾`)로 접힌다(열림 상태는 카드별 JS 상태).
- 펼친 영역에 없는 것: 토큰·비용·컨텍스트 바·Σ·압축·세션·merge, owner·workflow·마지막 활동, 이슈·PR 부제, 대화 링크, task 전체와
  이전 목록, 카드 안 에이전트 `전체 보기`, goal 편집기.

### 3.3 에이전트 트리 — 렌더러 하나, 밀도 둘 (`agentNodeRow(node, ctx, desc, open, line)`)

- 노드 모델·ARIA·키·접기 기본값·부모별 6개 상한은 spec 12 rev 2 그대로다.
- **compact**(펼친 카드): 아이콘 · 이름 · 상태 단어 · 시간(+N). 한 줄(`anCompactLine`)을 더하는 것은 실행·입력 대기·재개 대기·실패
  노드뿐이다 — 하는 일, 실패한 노드는 다른 말이 없으면 설명. 루트는 이름만(모델은 컨트롤 줄에 있다)이고, 그 한 줄은 접힌 카드의
  task 줄이 같은 task를 보일 때만 뺀다(그 외에는 마지막 도구·요약). 툴 수·토큰·배경·설명·waterfall은 없다. 접근 이름은 보이는
  칸만 나열한다(이름, 상태, 그 한 줄, 하위 N). 6개 넘는 부모의 나머지는 `전체 N개 → 상세` — 그 부모에 초점을 둔 패널을 연다(카드
  안에서는 펼치지 않는다, 예전에 켜 둔 상태도 무시).
- **rich**(패널 하위 트리): 상태 단어 · 시간 · 툴 수(루트는 task 완료/전체) · 토큰(서브, 하위 포함) · 배경 · 설명 · 하는 일 ·
  waterfall. 패널 안의 `전체 N개 보기`는 제자리에서 편다. 작업 로그의 자식 블록도 패널 밀도다.
- 패널 루트 초점 헤더: 루트의 상태·시간은 세션의 것 — 머리 칩이 보여 주므로 헤더는 툴 · 세션 Σ · 하위 전체 N만 보인다(접근 이름에는
  상태가 남는다). 서브에이전트 초점 헤더는 자기 상태·시간·토큰을 그대로 보인다.

### 3.4 패널

- 머리(고정): 제목 · 부제 · ×(`패널 닫기`). 칩 줄 `#panel-status`: `세션` + 상태 아이콘·단어(`role="status"` — 단어만 낭독, 1초
  시계는 낭독하지 않는다) + 활성 시간(`card-timer-live`) … 오른쪽에 Slack, 세션 액션 하나(접근 이름은 보이는 라벨이 먼저 —
  `Stop — 세션 중지`, `Close — 세션 종료`, `Trash — 세션 휴지통으로`; 소유자·형제 인스턴스 게이트는 카드와 같다, coarse ≥ 44px). 재개 대기면 그 아래 한 줄 `HH:MM 자동 재개 · 시도 n/3`.
- 고정: Tasks(+ 이전 목록), 산출물.
- 스크롤 영역: 세션 정보 `#panel-info` → goal `#panel-goal` → 권한 요청 → 질문 → 에이전트 → 작업 로그 → 대화.
  - 세션 정보: 접기(기본 접힘, 페이지 동안 JS 상태). 버튼이 요약 한 줄이다 — 소유자 · 워크플로 · 토큰 · 비용 · ctx % · 마지막 활동
    (실시간). 링크 줄은 접혀도 보인다. 펼치면 소유자·워크플로·환경·입력·출력·캐시 읽기·캐시 쓰기·비용, 컨텍스트 바 + autocompact,
    Σ 활성·압축·세션·merge, 재개 사유. 패널은 완전한 기록이라 카드 머리 설정(`dhShow`)을 따르지 않는다.
  - goal: 카드에 있던 goal 컴포넌트(`renderCardGoal`) 전체가 이리 왔다. 게이트는 카드와 같다(`canEdit = 소유자 && !형제 인스턴스`,
    `live = 칸 ≠ closed && !terminated`). 입력에 포커스가 있으면 쓰지 않고, 포커스 없는 초안은 새 markup으로 옮긴다. 다른 세션을 열면
    비운다(초안이 섞이지 않는다).
- 입력창(고정): `#panel-controls`(모델 · effort, 대기 전환 안내)가 입력 위의 자기 컨테이너에 있다 — 입력은 morph 대상이 아니다.
  640px 미만이거나 높이 560px 이하(폰 가로·키보드)면 토글 하나로 접히고, 접힌 토글은 입력과 같은 줄에 선다. 펼치면 선택은
  입력창 위에 떠서 열린다 — 읽기 영역의 높이를 빼앗지 않고, Escape는 패널보다 먼저 그 선택을 닫는다. 입력은 줄어들어도 Send는
  줄지 않는다(패널 밖으로 잘리지 않는다).
- 실시간: `repaintPanelSession()` 하나가 칩 · 세션 정보 · goal · 모델·effort · 노드 범위(spec 12의 `repaintPanelScope`)를 쓴다.
  `openPanel`, WS `session_update`·`sessionUpdated`, 폴링(`loadSessions`)이 모두 이 경로다. 부분마다 markup이 같으면 쓰지 않는다.
  읽던 자리: 갱신 전에 스크롤 영역에서 읽고 있는 앵커(질문·작업 로그·대화 턴)를 잡고, 위쪽 섹션 높이가 바뀌어도 그 자리로 되돌린다
  — 독자가 실시간 섹션(세션 정보·goal·에이전트)을 보고 있거나 최신 대화를 따라가는 중이면 건드리지 않는다.

### 3.5 쓰기 중 상태 (busy)

`_busy[key + '|' + op]`(op = model · effort · goal · action) 하나를 카드와 패널이 함께 읽는다. 요청 전에 켜고 끝나면 끈다. 켜져
있으면 그 컨트롤은 `disabled` + `aria-busy="true"`로 그려진다 — 포커스를 잃은 컨트롤이 실시간 렌더로 다시 켜지지 않는다. 오류는
세션별로 둔다 — 모델·effort 안내(`_modelNotes`)는 두 서피스에 같이, goal 오류(`_goalErrors`)는 goal 편집기가 있는 패널에 보인다.

### 3.6 착지와 포커스

`openPanel(key, intent, agentId, byKey)` — intent: `worklog`(작업 로그 버튼·`?session=`, `true`와 같다), `goal`(`관리 →`),
`agent`(트리 항목·`전체 N개 → 상세`), `tasks`(`전체 task N개 →` — 완료 펼침 + 이전 목록, 고정 Tasks 상자는 머리부터 보이고
대화 영역은 기본 착지), 없음(권한 요청·질문이 있으면 그 블록,
없으면 최신 대화 — spec 10 §3.1-6). goal·agent 착지는 열 때마다 한 번이고 대화가 늦게 와도 끌려가지 않는다. 키보드로 연 경우
(`event.detail === 0`, 트리 Enter) 포커스는 착지 대상(goal 입력, 초점 헤더, Tasks 영역, 작업 로그 머리, 없으면 답 버튼·제목)으로
간다. 닫으면(× · Escape) 포커스는 연 컨트롤로 돌아가고, 그 컨트롤이 사라졌으면 그 세션 카드의 face, 없으면 보드 제목으로 간다(포커스가
패널 안에 있었을 때만).

### 3.7 접힌 카드 감사 — 레퍼런스의 compact 층과 대조 (`renderCardFace`)

레퍼런스(§2, 조사 원문 §3.2·§4)가 compact 층에 두는 것은 상태, 주의가 필요한 이유, 진행 지표 하나, 최근성, 소유자, 결과 링크,
오류 상태다. 접힌 카드의 필드를 하나씩 대조했다.

| 필드 | 레퍼런스 | 판정 |
|---|---|---|
| 칸 + 바닥 줄 상태 | 상태 그룹(Cursor Needs Attention, Devin Blocked, Jules waiting) | 유지 |
| 제목 · 이유 줄(`cardSummary`: 권한 요청 → 질문 → `오류:` 재개 사유 → 요약) | 이유를 이름으로("Approve skill"), 오류 상태(Cursor) | 유지. 단 `오류:`는 자동 재개가 걸린 실패만이다 — 재개 없이 끝난 실패를 face가 따로 알리는 신호는 없다(미해결, 이전부터) |
| 진행 중 task `#T2 … 3m` | ★ 현재 task 한 줄 | 유지 |
| `완료/전체` | 진행 지표 하나(Jira 칸 체류, VS Code 변경 수) | 유지 |
| 서브에이전트 펄스 | 개수 배지("3 running") | 유지 |
| 소유자 배지(All Users) | 아바타 | 유지 |
| 토큰 · 비용 | 목록에 두는 제품 없음 | 유지 — 레퍼런스와 다르다. 유저 요청(10-22 T1/T2)이 우선(§4) |
| 산출물 칩 ≤ 4 | 개수 글리프 | 유지 — 레퍼런스와 다르다. 유저 요청(10-25 T5)이 우선, 이미지는 불러오지 않는다 |
| ctx % | 임계값에서만 경고(추론) | **개선** — 늘 보이는 숫자는 레퍼런스와 다르다(10 §2.1에서 유지), `ctxLevel`(60% 초과 `ctx-warn` = 아이콘 호박색, 80% 초과 `ctx-danger` = 빨강·굵게 + tooltip `80% 넘게 찼다`). 창 사용률의 구간이지 세션마다 다른 자동 압축 임계값이 아니다. 패널 컨텍스트 바와 같은 표 하나 |
| 결과 링크 | Copilot 목록의 PR 바로가기, Devin 행의 PR 목록, 권고 "PR 상태 글리프" | **추가** — `renderCardPr`: PR 글리프 + `#12 머지됨`. 상태는 화면에 보이는 단어(`.cpr-state` — 터치·키보드 독자에게 tooltip은 없으니 색만으로 말하지 않는다)와 색(열림 = 실행색, 머지됨 = 완료색, 닫힘 = 빨강 텍스트색 `--st-fail-text`, 초안 = 기본색). 상태를 모르면 번호만(대문자 상태값도 같은 상태로 읽는다). tooltip은 번호 · 상태 · 제목. 상태는 링크 메타데이터를 받아 온 때의 값이다 — 제목이 이미 있는 링크는 보통 다시 받지 않으므로, 밖에서 머지된 PR이 오래 이전 상태로 보일 수 있다(알려진 한계, 갱신 경로는 이 변경 밖 — #429). face는 토글 하나라 링크가 아니다 — 링크는 펼친 카드의 짧은 참조와 세션 정보. 펼친 카드에서는 번호가 배지(상태)와 짧은 참조(이동)로 두 번 보이는데, 하는 일이 달라 §0의 반복 금지에 걸리지 않는다. 헤더 필드 `links`를 따른다 |
| 최근성 | Codex `updated_at`, Jira 칸 체류(= 그 항목이 마지막으로 바뀐 때), 권고 `"2m ago"` | **추가** — `cardAgo`: 바닥 줄에 `· 12m ago`(1 Hz tick이 채운다, 마크업에 시계 없음). 질문 대기 카드는 기다리기 시작한 때(서버 `waitingSince` = 열린 권한 요청들과, 세션이 `waiting`이면 그 전환 시각 중 가장 오래된 것), 유휴·닫힘 카드는 작업이 끝난 때(서버 `finishedAt` = 살아 있는 카드는 idle로 바뀐 때, 보관 카드는 보관 기록이 지닌 완료 시각 — `ArchivedSession.doneAt`, 보관 때 idle·waiting 전환 시각 또는 실행 중이면 보관 시각). 정확한 시각이 없으면(상태 시각이 없는 기록, 이 필드 전에 쓴 보관 기록, 실행 중에 프로세스가 멈춰 재시작 때 휴면으로 바뀐 세션 — 로더가 그 상태 시각을 지운다) 나이를 보이지 않는다. 꺼져 있는 동안 만료돼 로드 중에 보관되는 세션도 저장된 상태 시각을 보관 기록으로 넘긴다 — `doneAt`은 날짜 그룹을 위해서만 마지막 활동으로 대신한다. `lastActivity`는 유저 입력에만 움직여 긴 턴 뒤에는 실제보다 길게 말하므로 쓰지 않는다. 실행 중은 활성 시간, 자동 재개는 그 시각을 이미 보인다 |
| 호버 메뉴(Close·Trash) | Claude Code·VS Code·Jules | 넣지 않는다 — 펼친 카드의 컨트롤 줄이 Enter 한 번 거리이고, 호버는 키보드·터치에 없다(GOV.UK: 카드 액션은 하나) |
| goal 제목 | 1–2줄 제목 | 넣지 않는다 — face의 제목 줄이 그 자리다. goal은 펼친 카드 한 줄과 패널 편집기 |

바닥 줄은 좁은 카드(820px 보드의 열, 폰)에서 상태를 자르지 않는다: 메트릭이 다음 줄로 내려가고(`flex-wrap`, `margin-left: auto`), 메트릭이 한 줄보다 길면 그 안에서 다시 줄을 바꾼다(`max-width: 100%`). 빨강 텍스트(컨텍스트 위험, 닫힌 PR)는 흐린 카드(휴면·보관 `#f8f8f8`) 위에서도 4.5:1을 넘는 `--st-fail-text`(라이트 `#c02f2f` 5.4:1)를 쓴다.
