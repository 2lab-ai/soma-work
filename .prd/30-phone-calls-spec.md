# 30 — 전화: 에이전트가 전화를 걸고 받고, 통화가 대화 안에 카드로 남는다

Status: in-progress

> 한 줄 결론: server-tools에 `phone_call` · `phone_calls`를 더한다. 환경(예: `2lab-ai-dev`)에 한국AI통신 번호를 두면
> soma-work가 그 번호로 걸고 받는다. 목소리는 사내 음성 서비스의 cwon(Drama 3), 대화 두뇌는 soma-work가 쓰는 같은
> 모델 경로(llmux)다. 건 통화는 그 세션의 대시보드 대화 안에 카드로 뜨고, 누르면 통화 내용이 채팅처럼, 통화
> 에이전트의 작업이 작업 로그처럼 열린다.

## 1. 지시

원문은 [phone-calls/ssot.md](phone-calls/ssot.md). 요지: 한국AI통신으로 전화를 걸고 받는 기능을 server-tools에, 설정은
로컬(`2lab-ai-dev` 환경)에만, 음성은 Drama cwon, 대화는 soma-work의 llmux 경로, 걸 때·받을 때 시스템 프롬프트와
대화 시나리오, 피클처럼 채팅 안 통화 카드 → 누르면 통화 내역이 채팅처럼 · 에이전트 작업은 자식 세션처럼.

## 2. 목표 · 비목표

목표

- G1. 모델이 대화 중 `phone_call`로 전화를 걸고, 상대와 음성으로 대화하고, 결과를 `phone_calls`로 읽는다.
- G2. 같은 번호로 걸려 온 전화를 soma-work가 받아 설정한 지시대로 대화한다.
- G3. 목소리는 cwon(Drama 3), 말은 soma-work의 모델 경로(`query()` → llmux)로 만든다.
- G4. 건 통화는 그 세션의 대시보드 대화 안에 카드(제목 · 번호 · 통화 시간 · 마지막 몇 마디)로 실시간으로 뜬다.
- G5. 카드를 누르면 통화 보기가 열린다: 통화 탭(말풍선 대화) · 작업 탭(받아쓰기 · 모델 응답 · 도구 · 음성 합성 기록).

비목표

- 여러 통화 동시 진행(번호당 한 통화. 통화 중 걸려 온 전화는 통화중으로 거절).
- 통화 녹음 파일 보관, 문자(SMS), 배치 발신, 통화 전환.
- dev 외 배포(prod · 고객 환경) — 설정은 로컬 dev에만 둔다.

## 3. 쓰는 사람이 보는 것

### 3.1 모델 (server-tools)

| 도구 | 하는 일 | 권한 |
|---|---|---|
| `phone_call` | `server`(환경) · `to`(번호) · `title`(카드 제목) · `purpose`(이번 통화의 목적) · `scenario`(대화 시나리오, 선택) · `max_minutes`(선택)로 발신. 통화 ID와 상태를 돌려준다 | write (요청자 기록 · 감사 원장) |
| `phone_calls` | `server`로 최근 통화 목록, `call_id`면 그 통화의 상태 · 시간 · 전사 · 요약. `wait_seconds`(≤ 300)를 주면 통화가 끝날 때까지 기다렸다 답한다 | read |

### 3.2 대시보드 — 대화 안 카드

- 통화를 건 턴의 답 아래 첨부 칸에 카드가 뜬다: 📞 제목, 상대 번호, 상태(거는 중 · 통화 중 · 끝 · 안 받음 …),
  통화 시간, 마지막 네 마디(상대는 왼쪽, 우리 에이전트는 오른쪽 말풍선).
- 통화가 진행되는 동안 카드가 실시간으로 바뀐다(WebSocket `phone_call_update`).
- 턴이 아직 기록되지 않은 동안의 통화는 마지막 턴의 첨부 칸에 붙는다.

### 3.3 대시보드 — 통화 보기 (세션 안의 세션)

- 카드를 누르면 열리는 창. 머리글: 제목 · 방향(건 전화/받은 전화) · 번호 · 상태 · 시작 시각 · 통화 시간.
- **통화** 탭: 전사를 채팅으로 — 상대 말은 왼쪽, 우리 에이전트 말은 오른쪽. 끊긴 말에는 "끊김" 표시.
- **작업** 탭: 통화 에이전트의 작업 기록 — 받아쓰기(걸린 시간), 모델 응답(모델 · 첫 토큰 시간), 도구 호출(통화 종료 ·
  키패드), 음성 합성(첫 바이트 시간), 오류. 일반 세션의 작업 로그처럼 시간순.
- 통화 지시(목적 · 시나리오)도 작업 탭 맨 위에 보인다.

### 3.4 받은 전화

- 환경 설정의 `inbound` 지시로 응대한다. 첫 인사는 고정 문장(설정)이고 기동 때 미리 합성해 둔다.
- 받은 전화는 특정 대화에 속하지 않는다. 끝나면 환경의 `owner`에게 슬랙 DM으로 요약과 통화 보기 링크
  (`/dashboard?phoneCall=<id>`)를 보낸다. 통화 보기는 owner와 어드민만 연다.

## 4. 결정

- **D1 연결은 데몬이 든다.** 플랫폼은 번호당 연결 하나만 허용하고(새 연결이 옛 연결을 끊는다), 세션마다 뜨는 stdio
  MCP는 그 연결을 들 수 없다. 별도 프로세스는 만들지 않는다(한 바이너리 원칙). 데몬이 기동 때 `phone` 절이 있는
  환경마다 연결을 연다.
- **D2 server-tools ↔ 데몬은 `DATA_DIR` 요청 파일.** server-tools가 `phone/requests/<id>.json`을 쓰고 데몬이 감시해
  건다. 결과 파일로 통화 ID를 돌려준다. 모델은 `DATA_DIR`에 쓰지 못하므로 요청은 server-tools만 만든다.
- **D3 목소리 = 음성 서비스 Drama 3, cwon.** 문장마다 스트리밍 합성(`/api/tts/stream`, pcm 44.1 kHz)을 8 kHz μ-law로
  바꿔 보낸다. 받아쓰기는 같은 서비스의 `/api/stt`.
- **D4 두뇌 = soma-work의 `query()` 경로.** 통화 한 건에 입력 스트림 `query()` 하나(통화 동안 CLI 하나). 인증은
  `ensureActiveSlotAuth` + `buildQueryEnv(lease, { llmuxTenant: 요청자 키 })` — 제목 생성기와 같은 길. 모델은
  `phone.model`(기본: 요청자의 aux `sonnet` 등급), 생각 끔. 도구는 통화 종료(`hang_up`) · 키패드(`send_dtmf`)만.
- **D5 지시의 층.** 기본 통화 규칙(짧은 구어, 마크다운 금지, AI냐고 물으면 사실대로, 끝나면 인사 후 `hang_up`) →
  환경 지시(`outbound.systemPrompt` / `inbound.systemPrompt`) → 이번 통화(`purpose` · `scenario` · 요청자).
- **D6 첫 마디.** 발신: 신호가 가는 동안 첫 인사를 만들어 합성해 두고, 상대가 받은 뒤 상대의 첫 말("여보세요")이
  끝나거나 1.2초 조용하면 바로 튼다. 수신: 고정 인사를 바로 튼다.
- **D7 끼어들기.** 에이전트가 말하는 중 상대가 말하기 시작하면 재생을 비우고(`clearAudio`) 남은 합성 · 생성을 멈춘다.
  자기 목소리 메아리를 끼어들기로 오인하지 않게 말하는 동안 기준을 8 dB 높인다.
- **D8 통화는 세션의 첨부 기록.** Slack 없는 세션은 만들지 않는다(#855). 통화 기록은 `DATA_DIR/phone/calls/<id>.json`에
  두고, 건 세션의 `conversationId`로 묶는다. 대화 화면은 산출물과 같은 첨부 칸에 카드를 넣는다.
- **D9 안전.** `phone_call`은 write — 요청자(`SOMA_REQUESTER`)가 없으면 거부, 감사 원장에 의도 · 결과를 남긴다.
  환경의 `outbound.allowTo`가 있으면 그 번호만 건다. 한 통화는 `max_minutes`(기본 5, 상한 `outbound.maxMinutes`)에서 끊는다.
  API 키는 시크릿 저장소에만 있고 어떤 모델도 보지 않는다.

## 5. 인수 시나리오

| ID | 실행 | 기대 관측 |
|---|---|---|
| A1 | 로컬 dev 설정에 `2lab-ai-dev`의 `phone` 절과 시크릿을 둔 뒤 데몬을 띄운다 | 로그 `phone: 2lab-ai-dev connected`, `list`에 `2lab-ai-dev`가 보인다 |
| A2 | 대화에서 "내 번호로 전화 걸어 오늘 할 일 물어봐" → 모델이 `phone_call` | 소유자 휴대폰이 울리고, 받으면 cwon 목소리로 첫 인사 |
| A3 | 통화 중 말을 건다 | 에이전트가 듣고 llmux 모델로 답한다(작업 탭에 모델 · 시간) |
| A4 | 에이전트가 말하는 중 끼어든다 | 재생이 멈추고 새 말에 답한다 |
| A5 | "이제 끊자" | 에이전트가 인사하고 `hang_up` — 카드 상태 "끝", 통화 시간 확정 |
| A6 | 대시보드에서 그 세션을 연다 | 답 아래 통화 카드(제목 · 번호 · 시간 · 마지막 마디). 누르면 통화 보기의 통화 · 작업 탭 |
| A7 | 그 070 번호로 전화를 건다 | 수신 인사 후 대화, 끝나면 owner DM에 요약과 링크 |
| A8 | 모델이 `phone_calls`(call_id, wait_seconds) | 끝날 때까지 기다렸다 상태 · 시간 · 전사를 돌려준다 |

## 6. 범위 밖 · 후속

- 동시 통화, 녹음 보관, 통화 전환, 문자.
