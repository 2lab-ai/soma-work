## 고정 스코프 (SSOT_2에서)

- 대상 = goal에 관한 코드 전체: 데이터 모델, 루프(평가·연속 턴·한도·stall·태스크 게이트·큐·일시정지), 호스트 연동
  (턴 시작·끝, 재시작 복구, 팔로업, 멈춤), 사람·모델이 goal을 바꾸는 표면(명령, 버튼, 대시보드, SET_GOAL).
- 할 일 = 코드에 암묵적으로 숨어 있는 상태(필드 조합, 플래그, 메모리 집합, 타이머, 프록시 추론)를 찾아 목록으로
  만들고, 그것을 이름 있는 상태와 전이로 명시해 한 곳에서 처리하도록 리팩토링한다.
- 완료 = 머지 + ‹소유자 dev 호스트› 배포 + 배포 뒤 실측(39 §인수 시나리오).
- 사람이 보는 동작은 바꾸지 않는다(리팩토링). 바뀌는 것은 숨은 상태 때문에 생긴 버그가 고쳐지는 것뿐이고, 그런
  변경은 39에 하나씩 적는다.
