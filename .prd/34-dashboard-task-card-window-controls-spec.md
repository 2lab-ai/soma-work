## 0. 한 줄 정의

작업 카드의 머리에 창처럼 버튼이 붙고, 버튼마다 하는 일이 하나다. 왼쪽 **−**는 카드를 한 줄로 줄이고(한 줄일 때는 **+**로 원래대로), **제목**은 오른쪽에 상세 카드를 열며, 오른쪽 **▽**는 카드를 제자리에서 펼친다(펼치면 **△**). 상세 카드가 열린 카드는 보드에서 한 줄이 되고, 상세 카드를 닫으면 원래 모습으로 돌아온다. 카드 면의 나머지는 눌러도 아무 일도 일어나지 않는다.

```
보통   [−] ✦ 제목…                  ★ [▽]      ← 요약 · 진행 중 작업 · 상태 · 비용 · 모델
       ──────────────────────────────────
한 줄  [+] ● 제목…                  ★ [▽]      ← 머리만 (상태 점)
펼침   [−] ✦ 제목…                  ★ [△]      ← 보통 + 제자리 본문(중지 · Slack · 승인 · 질문 …)
상세   [+] ● 제목…   ⧉ ← 강조 테두리  ★ [▽]      → 오른쪽 상세 카드 (덱 앞)
```

## 1. 지금 무엇이 예측을 깨는가 (실측, main `5c85d551`)

| 누른 곳 | 지금 일어나는 일 | 근거 |
|---|---|---|
| 카드 면 아무 곳 | 카드가 제자리에서 펼쳐지고 **동시에** 상세 카드가 덱 앞에 열린다 | `@2lab.ai/ui` `#onClick` → `.ib-face[role="button"]` → `#toggle` → `ui-toggle` → soma-work `wireInbox` → `openPanel(key)` |
| 펼친 카드 면 | 카드가 접히고 그 상세 카드가 덱에서 빠진다(다음 카드가 앞으로, 없으면 패널이 닫힌다) | `wireInbox` → `deckDrop(key)` |
| 덱 뒤 카드의 면 | 앞으로 오지 않고 **접힌다** | 15 §2 "뒤에 있는 펼친 카드를 누르면 그 카드가 접힌다" |
| 상세 카드 ✕ | 보드의 카드도 접힌다(면을 대신 누른다) | `closeDetailCard` → `cardFaceOf(key).click()` |

같은 면을 눌러도 덱에 있는지, 앞인지 뒤인지에 따라 결과가 셋으로 갈린다. 면 전체가 버튼이라 요약 글을 복사하려고 눌러도 카드가 움직인다.

### 결정

- **D1 — 상태 셋 + 상세 카드.** 카드는 한 줄 · 보통 · 펼침 중 하나로 보인다. 상세 카드(덱)는 따로다: 덱에 있는 카드는 보드에서 한 줄이다(D7).
- **D2 — 버튼마다 뜻 하나, 상태와 무관.**

  | 누른 것 | 한 줄 | 보통 | 펼침 |
  |---|---|---|---|
  | 왼쪽 버튼 | + → 원래대로(줄이기 전 보통/펼침) | − → 한 줄 | − → 한 줄 |
  | 제목 | 상세 카드(덱 앞) | 한 줄 + 상세 카드 | 한 줄 + 상세 카드 |
  | ▽ / △ | ▽ → 펼침 | ▽ → 펼침 | △ → 보통 |
  | ★ | 즐겨찾기 토글 (그대로) | ← | ← |
  | 면의 나머지 | 없음 | 없음(글 선택 가능) | 없음 |

  Esc(펼친 카드 안) = △. 키보드는 세 버튼 모두 Tab · Enter · Space.
- **D3 — 아이콘.** −(한 줄로), +(원래대로), 둥근 꼭짓점의 채운 역삼각형 ▽(펼치기, 펼치면 180° 돈 △). 평소엔 흐린 글자색, 호버 · 포커스에서 진해진다. 크기 28px, 터치 포인터 · 640px 미만에서는 누르는 자리만 44px(그림과 머리 높이는 그대로).
- **D4 — 제목은 상세 카드를 여는 버튼.** `<button>`이고 이름은 제목, 설명은 "상세 카드 열기". 호버 · 포커스: 강조색 밑줄, 제목 뒤 ⧉(옆 패널) 글리프가 4px 미끄러져 들어온다, 커서 pointer. 강조 테두리 카드(D5)는 ⧉가 늘 보인다.
- **D5 — 보고 있는 카드.** 덱 앞 카드는 보드에서 2px 강조 테두리, 제목 `aria-current="true"`. 덱 뒤 카드는 표시 없음(한 줄인 것으로 덱에 있음을 안다).
- **D6 — 펼침 애니메이션(▽ → △, 560ms).** 0–28% 제자리 점프(−7px)하며 1.35배로 커지고 아래 바닥 그림자(타원)가 작고 흐려진다 · 28–68% 공중에서 180° 회전 · 68–80% 내려앉으며 납작(가로 1.18, 세로 0.82) · 80–100% 제 크기. 내려앉는 순간(392ms) 바닥에서 먼지 알갱이 5개가 좌우로 1–12px 퍼지며 사라진다(320ms). 그 전에는 알갱이가 보이지 않는다(fill `forwards`). △ → ▽는 220ms 회전만. 감소된 모션: 점프 · 먼지 없음, 회전도 즉시. 본문 펼침(높이)은 지금과 같은 그리드 전환이 같이 돈다.
- **D7 — 상세 카드 ⇔ 한 줄.** 상세 카드가 열리면(제목, 딥 링크, "관리 →" · 계획 직접 입력 등 `openPanel`을 부르는 모든 길) 그 카드는 보드에서 한 줄이 된다 — "상세 카드에서 줄였음"으로 기억한다. 상세 카드가 덱에서 빠지면(✕ · Esc · 시트 배경 · 세션 교체) 그렇게 줄어든 카드만 원래대로 돌아온다. 그 사이 사람이 − · + · ▽를 누른 카드는 사람의 선택을 따른다(되돌리지 않는다).
- **D8 — 저장.** 사람이 −로 줄인 카드는 이 브라우저에 저장된다(`localStorage` `soma-card-min`, 최근 300개). 상세 카드로 줄어든 것은 저장하지 않는다(덱은 새로 고침을 넘지 않는다).
- **D9 — 그대로인 것.** 결정 대기 카드를 페이지가 스스로 제자리 펼침하는 것(`autoOpenDecisions`, 상세 카드는 안 연다), 별, 파일 칩 · 링크 · 후속 작업 · 에픽 자식 줄(각자 자기 일), 덱 ‹ › 넘기기, 폰(<840px)의 전체 화면 시트.
- **D11 — 한 줄이어도 TL;DR은 보인다 (SSOT_2-1).** TL;DR이 있는 카드는 한 줄로 접혀도 머리 아래에 TL;DR 상자를 둔다(라이브러리 `.ib-min-tldr`, 카드의 rows에 TL;DR이 있을 때만). TL;DR의 ×(`ui-dismiss` → `tldrDismiss`, 이 브라우저에 그 TL;DR을 지웠다고 저장)를 누르면 상자가 빠지고 그제서야 머리 한 줄이다. 포커스는 그 카드의 제목으로 간다.
- **D12 — 하루 지난 즐겨찾기는 한 줄로 시작 (SSOT_2-2).** 즐겨찾기 카드는 휴면 · 보관되지 않아 보드에 계속 남는다. 마지막으로 움직인 지(`lastActivity`) 24시간이 지났고 일하는 중도 응답 필요도 아니면, 보드가 그 카드를 처음 그릴 때 한 줄(+ TL;DR, D11)로 시작한다(`cardMinSeeds` → `data.minimized`). 사람이 +로 펼치면 `soma-card-unfold`에 저장되어 기본보다 앞선다(다시 −를 누르면 지워진다). 열어 둔 화면에서 24시간을 넘는 순간 접지는 않는다(다음에 그릴 때).
- **D10 — 라이브러리 경계.** 버튼 · 상태 · 애니메이션은 `@2lab.ai/ui` `<ui-agent-inbox>`의 opt-in(`data.controls = 'window'`)이다. 다른 소비자는 지금 그대로(면 = 토글). soma-work는 보드 · CRON 줄의 모든 요소에 켠다.

## 3. 라이브러리 계약 (`@2lab.ai/ui` 0.43.0)

| 항목 | 계약 |
|---|---|
| `data.controls: 'window'` | 모든 카드 머리에 왼쪽 버튼(`data-win="min"`, `aria-pressed` = 한 줄) · 제목 버튼(`data-win="detail"`) · 오른쪽 캐럿(`data-win="expand"`, `aria-expanded`, `aria-controls`). 면은 `role="button"`이 아니다. 본문이 없는 카드(스켈레톤 · 시작 중)는 캐럿이 없다 |
| `data.minimized: string[]` | 처음 그려질 때 한 줄로 시작하는 카드(이후엔 사람의 선택) |
| `data.current: string` | 강조 테두리 + 제목 `aria-current="true"`인 카드 |
| 한 줄의 상태 · TL;DR | 한 줄 카드의 머리에 상태 점(낭독기는 상태 낱말). TL;DR이 있으면 머리 아래 TL;DR 상자(×까지) |
| `ui-minimize` `{ cardId, minimized }` | 왼쪽 버튼 · 한 줄에서 ▽. 취소 가능 |
| `ui-detail` `{ cardId }` | 제목. 취소 가능. 취소되지 않으면 카드는 한 줄이 되고 "상세 카드에서 줄였음"이 된다 |
| `ui-toggle` `{ cardId, expanded }` | 캐럿 · Esc. 지금과 같다 |
| `setMinimized(id, on, { untilRestore })` | 이벤트 없이 바꾼다. `untilRestore`면 "상세 카드에서 줄였음" |
| `restore(id)` | "상세 카드에서 줄였음"인 카드만 원래대로. 바꿨으면 true |
| 상태 모델 | `open`(본문)과 `min`(한 줄)은 따로 기억한다. 보이는 것 = min이면 한 줄, 아니면 open이면 펼침, 아니면 보통. 그래서 펼친 카드를 줄였다 되돌리면 펼친 채로 돌아온다 |

## 5. 인수 시나리오

1. 보드에서 보통 카드의 −를 누른다 → 카드가 머리 한 줄(높이 ≤ 44px)이 되고 버튼이 +로 바뀐다. 오른쪽 패널은 그대로. 새로 고침 → 여전히 한 줄.
2. +를 누른다 → 보통으로 돌아온다(요약 · 상태 줄이 다시 보인다).
3. 보통 카드의 ▽를 누른다 → 캐럿이 점프 · 회전 · 먼지와 함께 △가 되고 본문(중지 · Slack …)이 제자리에서 펼쳐진다. **상세 카드는 열리지 않는다**(`#slide-panel` 닫힘). △ → 보통.
4. 제목에 호버 → 밑줄 · ⧉ · 툴팁 "상세 카드 열기". 누른다 → 카드가 한 줄 + 강조 테두리, 오른쪽에 그 상세 카드.
5. 다른 카드 B의 제목 → B가 한 줄 + 강조, 상세 카드 덱 앞이 B, A는 한 줄로 남고 강조가 B로 옮겨진다. ✕ → B는 보통으로 돌아오고 A가 앞(강조), 다시 ✕ → A도 보통, 패널 닫힘.
6. −로 줄인 카드 C의 제목 → C의 상세 카드가 열린다. ✕ → C는 한 줄로 남는다(사람이 줄인 것).
7. 펼친 카드의 제목 → 한 줄 + 상세 카드. ✕ → 펼친 채로 돌아온다.
8. 카드 면의 요약 글을 누르거나 끌어 선택한다 → 아무 일도 일어나지 않는다(선택만 된다).
9. 감소된 모션 → 3에서 점프 · 먼지 없이 △로 바뀐다.
10. 키보드: Tab으로 − → 제목 → ★ → ▽ 순서. Enter로 각각 위와 같은 결과. 펼친 본문 안 Esc → △와 같고 포커스는 캐럿.
